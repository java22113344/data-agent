Getting Started

Ready in four steps

⬇ Step 1 — Download the installer

Select Download DataAgent-Setup.exe above (roughly 300–400 MB — the exact size of the current release is shown on the release page). The complete platform ships in this one file, so there are no additional application components to obtain. The one optional extra download is the local model used for AI chat — see AI Setup below.

💻 Step 2 — Run the installer

Open the downloaded file and follow the setup wizard. Windows SmartScreen may ask you to confirm the publisher — choose More info, then Run anyway to continue.

Installed to C:\Program Files\DataAgent Start Menu DataAgent, DataAgent (web) Desktop Optional shortcut

⚡ Step 3 — Open your workspace

DataAgent can start as soon as setup completes, or any time afterwards from the Start Menu. Your workspace opens automatically in the default browser — there are no addresses to remember and no services to start.

🔑 Step 4 — Create your account and connect your AI

Open the app and register the first user, then choose your AI provider in Settings. Authentication is always required and there is no built-in admin account.

First Register your user in the app Next Settings — AI Provider Then Settings — Account

💼 Prefer not to install?

The portable build is a single self-contained application you can keep in any folder, including a USB drive. It leaves no trace in Program Files and needs no uninstallation — simply remove the file and its data folder when you are finished.

🗑 Uninstalling

Open Settings > Apps > Installed apps > DataAgent > Uninstall, or use the Uninstall DataAgent shortcut in the Start Menu. Your warehouse files remain in the data folder until you delete them, so backing up before removal is straightforward.

AI Setup

Choose your AI provider

🌐 Local models with Ollama (Recommended)

Run capable AI models on your own machine with no API costs and no data leaving the device. DataAgent can install Ollama for you in one click from Settings — or you can install it yourself — and it recognises Ollama automatically. The model is pulled once (about 4.7 GB for the recommended qwen2.5:7b) and then runs entirely offline. SQL, Excel, dashboards and exports do not need a model at all.

First Install Ollama for Windows: https://ollama.ai/download Second Pull a recommended model: ollama pull qwen2.5:7b Third Select Ollama under Settings — AI Provider

⚡ Cloud models with an API key

Connect GPT-4o, Claude, Gemini, DeepSeek, or Groq by pasting a key into Settings. Providers can be switched at any time, and nothing is sent to them until you ask a question.

OpenAI GPT-4o, GPT-4o-mini Anthropic Claude 3.5 Sonnet Gemini Gemini 1.5 Pro DeepSeek DeepSeek Chat, DeepSeek Coder Groq LLaMA 3 on Groq (low latency) xAI Grok-2
