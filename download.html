System Requirements

Everything you need, already included

Operating System
Windows 10 or Windows 11 • 64-bit (x86_64)
Memory
The app itself is light. The demanding part is a local LLM — qwen2.5:7b is a 7-billion-parameter model, and how fast it answers depends on your RAM and on whether you have a GPU
Storage
Roughly 0.7–1 GB once the application is installed, plus your own data — and about 4.7 GB more if you add a local AI model
Graphics
Optional. A local model runs on the CPU on its own; an NVIDIA GPU only makes it faster
Permissions
Standard administrator approval for installation — the installer writes to C:\Program Files
Preparation
None for the app — the platform and its runtime are packaged in the installer. AI chat additionally needs Ollama, which the app installs for you in one click from Settings, plus a one-time model download (about 4.7 GB for qwen2.5:7b). SQL, Excel, dashboards and exports need no model at all
Connectivity
Works fully offline; the network is used for the GitHub update check, the Ollama model pull, and optional cloud AI
Getting Started

Ready in four steps

Step 1 — Download the installer

Select Download DataAgent-Setup.exe above (roughly 400 MB). The complete platform ships in this one file, so there are no additional application components to obtain. The one optional extra download is the local model used for AI chat — see AI Setup below.

Step 2 — Run the installer

Open the downloaded file and follow the setup wizard. This release is not code-signed yet, so Windows SmartScreen will show “Windows protected your PC” and an “Unknown publisher” warning — choose More info, then Run anyway to continue.

Installed to C:\Program Files\DataAgent Start Menu DataAgent, DataAgent (web) Desktop Optional shortcut

Step 3 — Open your workspace

DataAgent can start as soon as setup completes, or any time afterwards from the Start Menu. DataAgent opens the workspace in its own window; the DataAgent (web) shortcut opens the same workspace in your default browser. Either way there are no addresses to remember and no services to start.

Step 4 — Create your account and connect your AI

Open the app and register the first user, then choose your AI provider in Settings. Authentication is always required and there is no built-in admin account. On a fresh install the first account you register is the local administrator — there is no bootstrap token and no cloud sign-up to get through first.

First Register your user in the app Next Settings — AI Provider Then Settings — Account

Prefer not to install?

The portable build is a single self-contained application you can keep in any folder, including a USB drive. It leaves no trace in Program Files and needs no uninstallation — simply remove the file and its data folder when you are finished.

Uninstalling

Open Settings > Apps > Installed apps > DataAgent > Uninstall, or use the Uninstall DataAgent shortcut in the Start Menu. Your warehouse files stay in the data folder until you delete them, so back it up before you remove the app.

AI Setup

Choose your AI provider

Local models with Ollama (recommended)

Run capable AI models on your own machine with no API costs and no data leaving the device. DataAgent can install Ollama for you in one click from Settings, or you can install it yourself; it recognises Ollama automatically. The model is pulled once (about 4.7 GB for the recommended qwen2.5:7b) and then runs entirely offline. SQL, Excel, dashboards and exports do not need a model at all.

First Install Ollama for Windows: https://ollama.ai/download Second Pull a recommended model: ollama pull qwen2.5:7b Third Select Ollama under Settings — AI Provider

Cloud models with an API key

Connect GPT-4o, Claude, Gemini, DeepSeek, or Groq by pasting a key into Settings. Providers can be switched at any time, and nothing is sent to them until you ask a question.

OpenAI GPT-4o, GPT-4o-mini Anthropic Claude 3.5 Sonnet Gemini Gemini 1.5 Pro DeepSeek DeepSeek Chat, DeepSeek Coder Groq LLaMA 3 on Groq (low latency) xAI Grok-2

Where your files live

Every dataset, dashboard and configuration file stays on your machine, inside one per-user data folder. The installer itself lives in Program Files; your data does not.

Installed version %LOCALAPPDATA%\DataAgent Portable version a data folder next to the application In there data\ the DuckDB warehouse and your uploads logs\ app.log, audit.log, runtime-stdout.log config\ your settings Backup or migration Close the app, then copy the whole folder

Copy the folder while the app is closed: DuckDB allows a single writer per file, so a warehouse copied mid-run can be inconsistent. The folder survives an uninstall — reinstalling finds your data and your plan where you left them.

What this build does not do

Better to say it now than to have you find out later:

Windows only The packaged download is Windows 10/11, 64-bit. macOS and Linux are not packaged; the source runs there if you bring your own Python. Cloud connectors No S3, GCS or Azure Blob. Live database connections are SQLite, PostgreSQL and MySQL only. PDF export The PDF in this build is a plain text summary, not a laid-out report. Excel, PowerPoint, HTML, Markdown, CSV, Parquet and .pbix are the fully formatted exports. One warehouse Everything lives in one DuckDB file, and only one process may write to it at a time. No hosted service There is no cloud DataAgent to sign up for. This release is the desktop app.
