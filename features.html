Full Capabilities

Every feature you need in one platform

30+ features spanning AI-powered chat, SQL exploration, dashboards, data warehousing, enterprise security, and multi-format export.

AI & Analytics

Natural Language Chat

Ask questions in plain English or any language. The AI understands context, remembers previous questions, and follows up intelligently.

Core AI

SQL Generation

AI automatically generates optimized SQL from natural language. Review, edit, and re-run queries. Supports complex joins, aggregations, and window functions.

SQL

SQL Explorer

Full SQL editor with syntax highlighting, autocomplete, query history, and inline results. Write raw SQL alongside AI-generated queries.

SQL

Automated Insights

Statistical profiling, correlation detection, anomaly flagging, distribution analysis, and trend detection — run automatically on any dataset.

AI

Smart Suggestions

The AI agent proactively suggests follow-up questions, visualizations, and deeper analyses based on your data and conversation history.

AI

Multi-Provider AI

Switch between Ollama, OpenAI, Anthropic, Gemini, DeepSeek, Groq, xAI, and more. Use local models for privacy or cloud for power.

AI

Visualization & Dashboards

30+ Chart Types

Bar, line, pie, scatter, heatmap, treemap, funnel, radar, box plot, waterfall, Sankey, network graph, word cloud, and many more.

Charts

Dashboard Builder

Drag-and-drop dashboard canvas. Arrange KPI cards, charts, tables, and text. Real-time preview. Responsive grid layout.

Dashboard

Power BI Export

Export dashboards as a real .pbix with your data — star schema and DAX measures included. Open directly in Power BI Desktop with layouts, themes, and data models intact.

Export

Chart Screenshot

Export any chart as high-resolution PNG or SVG. Perfect for presentations, reports, and documentation.

Export

PDF (basic) & PowerPoint

Export a dashboard as a PowerPoint deck with KPI cards, chart images and data tables, or as a basic text-only PDF. The fully formatted PDF report needs a rendering engine that is not bundled in the Windows build.

Export

Excel Export

One-click export to .xlsx with per-widget sheets, formatted tables, and a summary sheet. Opens in Excel, Google Sheets, or LibreOffice.

Export

Data Management

File Upload

Upload CSV, Excel (XLSX/XLS), JSON, Parquet, and TSV files. Automatic schema detection, type inference, and column profiling on import.

Data

Database Connectors

Connect to PostgreSQL, MySQL and SQLite. Sync schemas, query live data, or import snapshots into the warehouse.

Data

ETL Pipelines

Build data transformation pipelines with a visual editor. Clean, join, aggregate, and reshape data with no code. Schedule automated runs.

ETL

Data Catalog

Auto-discovered metadata, column descriptions, data lineage graphs, and quality scores. Know what your data means at a glance.

Catalog

Quality Monitoring

Automated data quality checks: null detection, range validation, uniqueness, freshness, and consistency. Alerts on quality degradation.

Quality

Data Lineage

Track how data flows from source to dashboard. Visual lineage graphs show transformations, joins, and dependencies between tables.

Lineage

Enterprise & Security

Role-Based Access

Admin, Editor, and Viewer roles. Control who can upload data, run queries, modify dashboards, or manage settings.

Security

SSO Integration ships disabled

OpenID Connect and SAML 2.0 support. Integrate with Okta, Azure AD, Google Workspace, Keycloak, and other identity providers.

SSO

Audit Logging

Complete audit trail of all user actions: logins, queries, data exports, setting changes, and dashboard modifications. Exportable logs.

Compliance

API Key Management

Generate, rotate, and revoke API keys for external integrations. Scoped permissions, rate limiting, and usage tracking.

API

Row-Level Security ships disabled

Filter data per user role. Different users see different subsets of the same table. Enforced at the query engine level.

Security

One-File Windows Install

Everything ships inside a single DataAgent-Setup.exe — runtime, backend, and UI. Install it, or run the portable DataAgent.exe with no install at all.
