How it works

CSV to boardroom
in five steps

Scroll sideways through the pipeline — every step runs on your machine.

01
💻

Install

Download the Windows .exe and run it. No developer setup — you create a local account on first launch, with no cloud sign-up, no email verification and no card required.

02
🗃

Connect data

Drop a CSV/XLSX, or point at Postgres, MySQL, or your existing warehouse. Schema is inferred on import.

03
🤖

Ask anything

Plain-English questions become SQL, run locally, and come back with charts — via Ollama or your cloud keys.

04
📊

Build the view

Pin charts to a live dashboard on a drag-and-drop canvas. 30+ chart types, real-time warehouse refresh.

05
📥

Ship it

Export a real .pbix for Power BI, or PDF, PowerPoint, Excel, CSV — the data itself never leaves your machine.
