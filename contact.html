What to expect

A reply, eventually. This is a small project with no support SLA. Bug reports and paid-plan questions are answered first; feature requests are read, and are often answered with the part of the plan that already covers them. The form above only sends if this deployment has a form endpoint configured — if it does not, it tells you so and points you at the email address and the issue tracker, which always work.

What to include. The app version (Settings → API Server), your Windows version, and what you expected to happen instead. For a crash, attach only these three files from %LOCALAPPDATA%\DataAgent\logs:

  • app.log
  • audit.log
  • runtime-stdout.log

Never send the warehouse file, your uploaded data, your API keys, data\.jwt_secret or data\.grant_key. If you are unsure whether a file is sensitive, leave it out and describe the problem instead.

Security reports go to the same address — there is no PGP key and no bug bounty, so please do not send anything sensitive, and give us a reasonable amount of time to ship a fix before disclosing details.

Frequently Asked

Is DataAgent really free?

There is a free tier and there are paid tiers, and the only price list is in rupees: Free is ₹0 (25 AI requests a day), Pro is ₹499/mo, Lifetime is ₹10,000 once. The source is open under the GNU AGPL v3 licence, so you can also read it, fork it and run it yourself. See pricing for what each plan unlocks.

Does my data leave my computer?

Not unless you configure a cloud LLM provider. With Ollama or LM Studio running locally, everything stays on your machine — the analytics engine, the data warehouse, and the AI inference. The security page lists every outbound connection the app can make.

Can I use it commercially?

Yes. DataAgent is open source under the GNU AGPL v3 licence — you may use it for personal projects, internal tools and client deliverables. AGPL has one condition: if you modify it and let users interact with it over a network, you must offer those users the modified source. Running it unmodified, including self-hosting it for your own team, triggers none of that. Full terms are in the LICENSE file at the root of the repository.

How does Power BI export work?

DataAgent generates a real .pbix file that contains your data — not a screenshot, and not an empty .pbit template. The exported file carries your layout, your theme, a star-schema data model and the DAX measures behind your KPI cards, so it opens in Power BI Desktop with the data already in it. DataAgent also imports existing .pbix and .pbit files and rebuilds them locally. The PDF export is the exception: in this build it is a plain text summary, not a laid-out report.
