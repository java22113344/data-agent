Frequently Asked

Is DataAgent really free?

Yes. The core product is free and open source forever. Optional paid plans unlock higher entitlements such as a larger daily AI allowance and Power BI export — see pricing. If you use local LLMs via Ollama, there are zero ongoing costs.

Does my data leave my computer?

Not unless you configure a cloud LLM provider. With Ollama running locally, everything stays on your machine — the analytics engine, the data warehouse, and the AI inference.

Can I use it commercially?

Yes. DataAgent is open source under the GNU AGPL v3 licence — you may use it for personal projects, internal tools and client deliverables. AGPL has one condition: if you modify it and let users interact with it over a network, you must offer those users the modified source. Running it unmodified, including self-hosting it for your own team, triggers none of that. Full terms are in the LICENSE file at the root of the repository.

How does Power BI export work?

DataAgent generates a real .pbix file that contains your data — not a screenshot, and not an empty .pbit template. The exported file carries your layout, themes, star-schema data model and DAX measures, and DataAgent also imports existing .pbix/.pbit files and rebuilds them locally. Double-click the export in Power BI Desktop and it works.
