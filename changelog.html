v1.0.0 (current build) Latest Unreleased

This is the current state of the codebase. Work on DataAgent is recorded from 6 October 2026 and has been a single line of development since, so there is no dated public release history behind this entry — everything below ships in the build you download today.

What the app does

  • Natural-language chat over your local warehouse — the generated SQL is shown for every answer
  • SQL workbench, file upload (CSV, Excel, JSON, Parquet, TSV) and live database connections
  • Dashboard Studio: 30+ chart types on a drag-and-drop canvas, with .pbix export and .pbix import
  • ETL pipelines, data profiling, data catalog, lineage and scheduled reports
  • Ten LLM providers — Ollama, OpenAI, Anthropic, Gemini, DeepSeek, Groq, xAI, LM Studio and more
  • JWT authentication with Google sign-in, role-based access, SSO, audit logging and row-level security
  • MCP servers for DuckDB, memory and filesystem
  • Signed Windows .exe installer and a portable build, plus a Docker image for self-hosting

How it is built

  • Warehouse opened read-only for analysis; ETL writes funnel through one dedicated process
  • Web UI auto-reloads on change with WAREHOUSE_RELOAD=1
  • Quality is gated by the project's pytest suite and the coverage floor set in pyproject.toml

Hardened

  • Windows file-lock errors when two processes opened the DuckDB warehouse
  • Long-running queries no longer block the chat stream
  • First-admin takeover on an exposed port — creating the first admin now requires DATAAGENT_BOOTSTRAP_TOKEN
