FAQ

Questions, answered

The things people ask before installing — setup, pricing, privacy, and how it all fits together.

Getting started

What do I need to run DataAgent?
A Windows PC and one download. Grab DataAgent-Setup.exe, double-click it, and launch the app from the Start Menu — Python, the backend, and all dependencies are bundled inside the executable. Nothing else to install first, and no developer tools involved. There is also a portable DataAgent.exe if you would rather not install anything at all.
Does it run on macOS or Linux?
The packaged download is Windows-only today (Windows 10/11, 64-bit). The project is open source, so the same stack can be run from source on macOS or Linux if you are comfortable with a Python environment. The download page lists exactly what the Windows build needs.
Do I need my own LLM API key?
No key is required to install. For AI answers you choose a provider: a fully local model via Ollama (free, offline), or a hosted provider such as OpenAI, Anthropic, or Gemini with your own key. Ten providers are supported and you can switch at any time in the config.
What data sources can I connect?
Files upload directly — CSV, Excel, Parquet — and are ingested into the local DuckDB warehouse. Database connections are configured through db_connections.json. Dashboards can be imported from and exported to Power BI (PBIX).

Pricing

Is DataAgent really free?
Yes. The core product is free and open source — download it, read the code, self-host it. Paid plans (Pro at $6/mo ≈₹499, Lifetime at $120 ≈₹10,000) exist for teams that want support and premium features; checkout happens on Razorpay's secure payment page or our separate billing site. Self-host it with Docker and you get the full product — every feature — free forever, with no account and no card. Your hosted LLM provider (if you choose one) bills you directly.
What do paid plans add?
Higher entitlements — unlimited AI queries, advanced analytics, and Power BI export — plus priority support. The free tier is designed to cover real work, not a demo. Compare the plans on the pricing page.
Where does checkout happen?
On Razorpay's hosted payment page (UPI, cards, netbanking) via a payment link on the pricing page — or on our separate billing site, depending on configuration. The app itself never handles card data. See contact us for invoices or team licenses.

Privacy & security

Does my data leave my machine?
No telemetry, no analytics, no crash reporting, no background sync — ever. The warehouse is a local DuckDB file and the app runs on your machine. Outbound traffic goes to three places, and only these: the LLM provider you configure (choose Ollama for a fully offline setup); GitHub, for the update check; and, for Pro users only, the feature-ticket and entitlement service plus the proxy pool used by the IP-rotation feature. Details on the security page.
How is access controlled?
JWT-based authentication with hashed passwords (and optional Google sign-in). Secrets and signing keys live in gitignored files, are redacted from logs, and never enter model context.
Can the AI modify or delete my data?
No. Analysis opens the warehouse read-only and all SQL is parameterized. Writes happen only through explicit, user-triggered ETL runs handled by a single dedicated process.

Technical

Why DuckDB instead of a cloud warehouse?
Because it's embedded: no server to run, no cluster to pay for, and the whole warehouse is one file you control. It's an analytical engine fast enough for real workloads while keeping the data local — exactly the trade-off local-first requires.
Does it work offline?
Yes. The app installs with no setup — the runtime, the UI, the warehouse and ETL all ship inside the installer. For AI chat you additionally need a local model via Ollama: the app can install Ollama for you in one click from Settings, and it then downloads a model once (roughly 4.7 GB for the recommended qwen2.5:7b). SQL, Excel, dashboards and exports work with no model at all. After that, the network is only needed to pull a model or to call a hosted LLM provider.
Is there an API?
Yes — the same FastAPI backend powers the UI, with REST endpoints for chat, SQL, data management, auth, and export. See the API reference in the docs.
